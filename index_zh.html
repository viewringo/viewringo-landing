Databricks Genie Agents

用自然语言提问，即可获得附带依据 SQL 与图表的回答。

  • 两种模式 — 快速回答与深度分析
  • 依据可追溯 — 生成的 SQL · 分析步骤 · 图表
  • 保持用户权限 — 仅限于用户自身权限范围

ViewRingo Data Assistant

直接总结当前所看的界面，并用自然语言查询数据。

  • 界面摘要 — 一键完成，权限之外的报表不会被渲染
  • NL2SQL — MSSQL · PostgreSQL · Oracle
  • 经由服务器 — 所有请求均经过门户服务器

语义层

准确性来自经过审核的上下文，而非模型本身。

  • 人工审核的语义层 — 说明 · 同义词 · 指标 · 关系
  • 黄金集回归测试 — 定期检查答案是否发生反转
  • 执行前 SQL 校验 — 提前拦截不存在的列与语法错误
