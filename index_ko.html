왜 지금 Enterprise Analytics Portal인가

BI는 부서마다 늘어나는데, 사용자와 관리자는 그 사이를 오가며 같은 일을 반복합니다.

도구는 늘어난다

부서·계열사별 개별 도입이 누적되어 한 기업 안에 서로 다른 BI가 공존합니다.

권한은 갈라진다

도구마다 계정과 권한 체계가 달라, 같은 사람에게 같은 범위를 주는 일도 여러 번 반복합니다.

근거는 사라진다

보고서 숫자가 어느 테이블에서 왔는지, 바꾸면 무엇이 깨지는지 답할 수단이 없습니다.

96%자연어 데이터 질의로 성과 향상을 기대Salesforce 조사 · 국내 500사 포함, 2026

도구를 줄이지 않고 포털을 통합합니다.

Power BI Report ServerNEW

망분리·데이터 주권 환경에서, 클라우드 전환 없이 BI를 통합합니다.

  • PBIX · RDL 동시 지원 — 대화형과 페이지 보고서를 자동 식별
  • 기존 AD 권한 그대로 — Windows 통합 인증(Kerberos · NTLM)
  • 계층 트리 등록 — PBIRS 폴더 구조를 포털 메뉴에 반영

Databricks AI/BI DashboardNEW

Databricks 계정 없이, 포털에서 바로 대시보드를 봅니다.

  • 계정 없이 조회 — External Viewer 임베딩
  • 사용자별 토큰 — 권한 범위가 제한된 토큰만 브라우저로
  • 관리자 자동 매핑 — 게시된 대시보드 목록을 자동 조회

포털 안에서 움직이는 AI 분석

자연어 질의와 화면 요약을 포털 인증·권한 체계 안에서 제공합니다.

Databricks Genie Agents

자연어로 질문하면 근거 SQL과 차트까지 함께 답합니다.

  • 두 가지 모드 — 빠른 답변, 심층 분석
  • 근거 추적 — 생성 SQL · 분석 단계 · 차트
  • 사용자 권한 유지 — 본인 권한 범위 안에서만

ViewRingo Data Assistant

보고 있는 화면을 그대로 요약하고, 자연어로 데이터를 묻습니다.

  • 화면 요약 — 클릭 한 번, 권한 밖 보고서는 그려지지 않음
  • NL2SQL — MSSQL · PostgreSQL · Oracle
  • 서버 경유 — 모든 요청은 포털 서버를 지남

시맨틱 레이어

정확도는 모델이 아니라 검수된 문맥에서 나옵니다.

  • 사람이 검수한 의미층 — 설명 · 동의어 · 지표 · 관계
  • 골든셋 회귀 시험 — 답이 뒤집히는지 주기 확인
  • 실행 전 SQL 검증 — 없는 컬럼 · 문법 오류를 미리 차단
